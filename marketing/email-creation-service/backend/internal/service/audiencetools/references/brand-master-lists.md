# Brand Master Lists

These are the standing HubSpot master lists used to gate regional/geographic contact filters
(web-visitor filters do NOT use this gate). They represent the broad brand audience
(opt-in + event registrations + education enrollments).

| Brand Key | HubSpot List Name | List ID | Size (approx) | Notes |
|-----------|-------------------|---------|---------------|-------|
| lf | 26Q2 - The Linux Foundation - Master-list | 26716 | 2.5M | LF-wide audience; use for all direct LF events (Open Source Summit, Linux Security Summit, etc.) |
| grpconf | Q2 2026 - gRPConf NA CNCF - Project Events Master (With Opt-In and Filters) | 28488 | 200K | gRPConf / gRPC project audience under CNCF |
| opensearch | 26Q2 - OpenSearch Foundation - Master-list | 26730 | 2.5M | OpenSearch Foundation audience; use for all OpenSearchCon events |
