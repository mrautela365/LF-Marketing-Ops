NEW HELPER FUNCTIONS (7):
  1. _fill_template_placeholders(template_text, event_data) -> str
     Replaces: [Event Name], [City], [Dates], [Date]
     Example: "[Event Name] in [City]" + {event_name: "KubeCon", city: "Barcelona"}
              = "KubeCon in Barcelona"

  2. _get_variant_subject_preview(stage_name, variant_id, event_data) -> (str, str)
     Returns: (subject, preview) with all placeholders filled
     Uses _fill_template_placeholders internally

  3. _recommend_variant_strategy(stage_name) -> (str, str)
     Returns: (variant_id, reason)
     Stage-based recommendation logic:
       Final Countdown    -> v1_fomo_urgency
       Registration      -> v1_discount_focused
       Schedule Announce -> v1_keynote_focused
       etc.

  4. _format_variant_recommendations(stage_name) -> str

       - **v3_social_proof** (Social Proof & Community): ...
       Recommended: v1_discount_focused - proven to drive registrations

  5. extract_variant_id_from_messages(messages) -> str|None
     Parses user's variant choice:
       Looks for: "use variant v1_..."
       Checks tool_result blocks for select_template_variant calls
       Returns: variant_id or None

================================================================================
 USER JOURNEY WITH VARIANTS
================================================================================

PLAN PHASE:
  User Input: Event URL
    |
    v
  Agent detects stage: "Event Announcement"
    |
    v
  Agent calls: get_variant_strategies("Event Announcement")
    |
    v
  Returns: 3 variants
    - v1_value_focused: Learning + networking
    - v2_urgency_focused: Early bird savings
    - v3_social_proof: Testimonials + FOMO
    |
    v
  Agent recommends: v1_value_focused (best for early awareness)
    |
    v
  User says: "Use variant v2_urgency_focused" (or accepts recommended)
    |
    STORE: session.meta["stage_name"] = "Event Announcement"

CLONE PHASE:
  User Input: Approves plan
    |
    v
  clone_turn() extracts: variant_id = "v2_urgency_focused" (from user message)
    |
    v
  Generate: subject & preview from variant template
    Subject Template: "Early Bird Alert: [Event Name]..."
    Preview Template: "Early bird opens [Date]..."
    Event Data: {event_name: "KubeCon", date: "2026-06-16"}
    Result: Subject: "Early Bird Alert: KubeCon..."
            Preview: "Early bird opens 2026-06-16..."
    |
    v
  Clone email in HubSpot with these settings
    |
    v
  STORE: session.meta["selected_variant_id"] = "v2_urgency_focused"

CONTENT PHASE:
  User Input: Google Doc URL or HTML content
    |
    v
  content_turn() retrieves: variant_id = "v2_urgency_focused"
    |
    v
  Get variant template:
    - Strategy: "Highlights early bird savings and limited-time advantage"
    - Body template: "The moment you've been waiting for..."
    |
    v
  Pass to agent:
    "MESSAGING VARIANT SELECTED: v2_urgency_focused
     Strategy: Highlights early bird savings and limited-time advantage
     Template structure: The moment you've been waiting for...
     [first 500 chars of template]
     Use the user-provided content, but maintain the messaging strategy"
    |
    v
  Agent merges content while maintaining urgency tone
    |
    v
  Result: Draft email with variant-driven messaging + user's actual content
